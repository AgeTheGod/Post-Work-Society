#   Further Thoughts

So far everything I've written is about creating the basic Post Work Society, outlining what it should provide and how I think it would work. 
Exploring the Economics and the Politics and the Technology required to build a Post Work Society is useful to know (and very interesting to research) but, in the true spirit of "Iterative Development", this is just the start point.

The much more interesting questions relate to "_What comes afterwards?_". There are many outcomes and implications that only become important _after_ a Post Work Society becomes established.

This section is where these topics are going to be discussed.
